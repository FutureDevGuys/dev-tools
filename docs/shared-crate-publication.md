Every batch requires exact clean-source reconstruction, byte-identical independent archives, operation-only manifest signing, full local authentication, registry-visible dependency resolution, and anonymous index/checksum/download verification after publication. Missing bootstrap input blocks upload, not testing, source corrections or reproducible package preparation. Configure Trusted Publishing per published package and revoke bootstrap authority before routine successor publication; the bootstrap credential must never enter chat, argv, environment variables or a named file. The native contract and remaining cutover gates are defined in [ADR 0003](adr/0003-native-release-administration-and-separated-authority.md).
